# Changelog

## [2.0.0] - 2026-11-26

### Ajouté
- **Accueil en 4 portes** : Maths, Sciences, Programmation, Énigme du jour.
- **Énigmes du jour** en maths, sciences et code, regroupées dans un même écran.
- **Statistiques** par mode (parties, % de réussite, série, record) et **partage** façon Wordle.
- **PWA** : installable sur iPhone et Android, jouable hors ligne.
- **Maths** : Suites, Cible π, Courbes.
- **Chimie** : Élément mystère, Masse molaire, Oxydoréduction.
- **Physique** : Unités, Applications numériques, Conversions en chaîne.
- **Console Python / JavaScript** : vraie exécution dans le navigateur, tests cachés aléatoires, anti-triche.
- Code affiché avec lignes et indentation dans les énigmes de programmation.

### Modifié
- Conversions déplacées dans Physique ; Sciences séparées en Chimie et Physique.
- En Python et JavaScript, la Console remplace la Page blanche.
- La série de jours se casse si on saute un jour.

## [1.0.0] - 2026-11-24

### Ajouté
- Maths : Classique (4 niveaux dont Impossible) et Cible libre, système de vies.
- Sciences : Conversions, Équilibrage chimique (60 réactions), Formules physiques (55).
- Programmation : 72 exercices en JavaScript, Python, Java et C++ (Page blanche, Extrait à trous).
- Énigme du jour par matière, logo, aperçu pour les réseaux sociaux.
